# Stumblin' Bumblin' & Fumblin'

Official fantasy football league companion website.

## Included in this starter

- Live league information from the Sleeper public API
- Standings
- Owners and team names
- Responsive ESPN-inspired homepage
- Placeholder for draft and weekly recap editions

## League

Sleeper League ID: `1371503267833475072`

## Publish with GitHub Pages

1. Upload all files in this folder to the root of the repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

The website will then be available at:

`https://electricwrangler.github.io/Stumblin-bumblin-fumblin/`
